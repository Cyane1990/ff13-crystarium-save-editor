Final Fantasy XIII · PC save editorCrystarium Save Editor

Set each character's roles, abilities, passives and ATB segments, choose your party, make enemies tougher, and edit your items, weapons, accessories and components. Open an ff13-XX.dat save, make changes, then save the edited copy. Everything runs in this page; your save is not uploaded anywhere.

Open your save to edit it. This sample shows how the editor works.

ATB

Number of ATB segments in battle. The game's normal maximum is 6.

Roles

These are the role levels stored in the save. Raising a locked role to level 1 doesn't make its crystal appear in the Crystarium; the game adds the other roles' crystals through a story event in Chapter 10, which this editor can't trigger yet. You can still give any role's abilities in the lists below.

Passives

Passives such as Auto Haste come only from equipped gear; each accessory or weapon has one fixed passive. Add the item that carries the passive you want, then equip it on this character in the game's Equip menu. Weapon traits list only this character's weapons.

Other entries

Entries in this character's list that aren't regular Crystarium abilities. Passive IDs here (like auto_hast) don't do anything in the ability list; the game only applies passives from equipped gear. Entries marked in amber don't match any ID the game uses. Removing either kind is safe.

Battle team

The leader is the character you control in the field. Up to three characters fight; the leader slot can't be empty.

Reserve

Characters in the party but not fighting. You can swap them in from the Paradigm menu in game.

Story events can reset the party when a chapter changes it. A character added before they normally join may have no roles or abilities yet, and their paradigms may be blank; give them abilities on the Characters tab and check the Paradigm menu before a fight.

Enemy data

Enemy stats live in the game's own files, not in your save, so hard mode changes the game itself. Open these files from FINAL FANTASY XIII\white_data\sys: filelistu.win32.bin and white_imgu.win32.bin (English voices). Add filelistc.win32.bin and white_imgc.win32.bin too so it works with either voice setting. The big file is only read in part; nothing is uploaded.

Install

"Build hard mode" gives you a zip. Extract it into your FINAL FANTASY XIII folder (next to FFXiiiLauncher.exe), close the game, and run install.bat. It backs up the original data first; restore.bat puts it back. Your saves aren't touched.

1 · Back upClose the game. Copy your save folder somewhere safe first. Steam keeps saves in Steam\userdata\<id>\292120\remote.
2 · EditPick a character to set abilities and ATB, set the battle team on Party, or switch to Inventory. Equipped accessories can't be removed; unequip them in game first.
3 · Put it back"Save edited file" gives you the edited save (inside a .zip when this page is opened in Claude). Put the .dat into the save folder, replacing the original. If Steam reports a cloud conflict, keep the local file.
